# cup-shuffle-eye-training-game
⚠️NOT MOBILE FRIENDLY, PLEASE SKIP PROJECT IF REVIEWING ON MOBILE

a really really small game I made, a cup shuffling game with various levels! It's basically an eye training game.

There are ten total levels! Levels 1-5 have three cups and levels 6-9 has five cups. Level 10 is impossible, no one can beat it haha.
Basically, the ball starts inside the middle cup. And you have to use your eyes to remember the ball's position while the cups are getting shuffled. It might be a bit hard and confusing to see, sorry
